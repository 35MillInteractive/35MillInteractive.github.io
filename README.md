# Eric Tapia / 35 Mill Interactive

Static portfolio for world design, Conan Exiles mod development, Niagara VFX, and gameplay testing. No package installation or build step is required.

## Preview

From this folder, run:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Open http://127.0.0.1:8765/ in a browser. Stop the server with Ctrl+C when finished. The page can also be opened directly from index.html; the video and Google Fonts require an internet connection.

## Editing

- `index.html`: copy, project excerpts, links, and accessible native project disclosures.
- `style.css`: responsive layout; brand colors and fonts are in `:root`.
- `site.js`: mobile navigation only. Project disclosures work without JavaScript.
- `assets/`: original identity assets and optimized new branding/project images.
- `Eric_Tapia_GameDev_Resume.pdf`: original resume, preserved without content changes.

## Content and image context

The ShatterCross visual is AI-assisted concept artwork, not a game capture. The Homepoint Crystals image is promotional cover artwork; the embedded YouTube video supplies the gameplay demonstration. Magic Arts images are AI-assisted development references, with final in-game testing and polish ongoing. The aperture hero is newly generated decorative branding. Image labels and project descriptions preserve these distinctions.
